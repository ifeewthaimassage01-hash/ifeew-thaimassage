# นโยบายความเป็นส่วนตัว

Ifeew's Thaimassage ("ร้าน" หรือ "เรา") ให้ความสำคัญกับข้อมูลส่วนบุคคลของลูกค้า นโยบายนี้อธิบายว่าเราเก็บข้อมูลอะไร ใช้ทำอะไร ส่งให้ใคร เก็บนานแค่ไหน และคุณมีสิทธิ์อะไรบ้าง ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

## 1. ผู้ควบคุมข้อมูล

Ifeew's Thaimassage สาขาสุรินทร์
8/9 ถนนศิริรัฐ ตำบลในเมือง อำเภอเมืองสุรินทร์ จังหวัดสุรินทร์ 32000
โทร 092-576-6293 หรือทักแชท LINE Official Account ของร้าน

## 2. ข้อมูลที่เราเก็บ

**เมื่อคุณจองคิว**
- ชื่อ นามสกุล (ถ้ากรอก) เบอร์โทร และอีเมล (ถ้ากรอก)
- รายละเอียดการจอง: สาขา บริการ ระยะเวลา จำนวนคน วันและเวลานัด และหมายเหตุที่คุณเขียนถึงร้าน
- หลักฐานการชำระมัดจำ: รูปสลิปโอนเงิน ซึ่งมีชื่อผู้โอน ธนาคาร เลขบัญชีบางส่วน ยอดเงิน และเลขอ้างอิงรายการ
- การยอมรับนโยบายนี้ และการเลือกรับหรือไม่รับข่าวสารจากร้าน

**เมื่อคุณเข้าสู่ระบบด้วย LINE (ไม่บังคับ)**
- รหัสผู้ใช้ LINE ชื่อที่แสดง และรูปโปรไฟล์ เราไม่ได้รับรหัสผ่านหรือข้อความแชทอื่นของคุณ

**เมื่อคุณใช้บริการที่ร้าน**
- ประวัติการใช้บริการ หมอที่ให้บริการ ยอดชำระ วิธีชำระ และทิป

**ข้อมูลทางเทคนิค**
- หมายเลข IP ใช้ชั่วคราวเพื่อจำกัดจำนวนครั้งที่ส่งคำขอและป้องกันการใช้งานผิดปกติ
- เบราว์เซอร์ของคุณจำลิงก์ติดตามการจองล่าสุดไว้ในเครื่องของคุณเอง เพื่อให้กลับมาดูการจองได้ง่าย ข้อมูลนี้อยู่ในเครื่องคุณ ไม่ได้ส่งให้ใคร

เราไม่เก็บข้อมูลสุขภาพเว้นแต่คุณเขียนบอกเองในหมายเหตุ (เช่น เจ็บไหล่) และใช้เพื่อให้บริการครั้งนั้นเท่านั้น

## 3. เราใช้ข้อมูลทำอะไร และฐานทางกฎหมาย

| วัตถุประสงค์ | ฐานทางกฎหมาย |
|---|---|
| รับจอง จัดคิว จัดเตียงและหมอ ยืนยันหรือยกเลิกการจอง | การปฏิบัติตามสัญญาบริการ |
| ตรวจสลิปและบันทึกการชำระเงิน คืนเงินมัดจำ | การปฏิบัติตามสัญญา และหน้าที่ตามกฎหมายบัญชีและภาษี |
| ส่งข้อความยืนยันการจองและเตือนก่อนถึงนัดทาง LINE (เมื่อคุณเข้าสู่ระบบด้วย LINE) | การปฏิบัติตามสัญญาบริการ |
| แสดง "การจองของฉัน" และเติมชื่อกับเบอร์ให้ในการจองครั้งถัดไป (เมื่อเข้าสู่ระบบด้วย LINE) | การปฏิบัติตามสัญญาบริการ |
| ติดต่อคุณเรื่องการจอง เช่น ร้านปิดฉุกเฉิน | การปฏิบัติตามสัญญาบริการ |
| ป้องกันการจองปลอม สลิปซ้ำ และการใช้งานผิดปกติ ดูแลความปลอดภัยของระบบ | ประโยชน์โดยชอบด้วยกฎหมายของร้าน |
| ส่งข่าวสารและโปรโมชัน | ความยินยอมของคุณ (เลือกได้ ไม่บังคับ ยกเลิกได้ทุกเมื่อ) |

เราไม่ขายข้อมูลของคุณ และไม่ใช้ข้อมูลเพื่อโฆษณาของบุคคลอื่น

## 4. ใครเข้าถึงข้อมูลได้

**ภายในร้าน:** เจ้าของร้านและพนักงานหน้าร้านของสาขาที่คุณจอง เห็นเฉพาะข้อมูลที่จำเป็นต่อการให้บริการ หมอเห็นชื่อและบริการของคิวที่ตนรับ การแก้ไขข้อมูลการเงินทุกครั้งมีบันทึกว่าใครทำ

**ผู้ให้บริการที่ร้านใช้** (ประมวลผลตามคำสั่งของร้านเท่านั้น):
- Supabase: ฐานข้อมูลและที่เก็บไฟล์ของระบบ เซิร์ฟเวอร์อยู่ในสิงคโปร์
- Vercel: เว็บไซต์จองคิว
- LINE (LY Corporation): เข้าสู่ระบบด้วย LINE และส่งข้อความ
- SlipOK: ตรวจความถูกต้องของสลิปโอนเงิน (ได้รับรูปสลิปและยอดเงิน)
- Cloudinary: เก็บรูปภาพในระบบหน้าร้าน รวมถึงรูปสลิปที่ถ่ายตอนชำระเงินที่ร้าน
- Sentry: บันทึกข้อผิดพลาดของเว็บไซต์ (เฉพาะเมื่อร้านเปิดใช้)

ผู้ให้บริการบางรายเก็บข้อมูลบนเซิร์ฟเวอร์นอกประเทศไทย ร้านเลือกใช้ผู้ให้บริการที่มีมาตรการคุ้มครองข้อมูลที่เหมาะสม

**หน่วยงานรัฐ:** เมื่อกฎหมายกำหนด หรือมีคำสั่งจากหน่วยงานที่มีอำนาจ

## 5. เก็บนานแค่ไหน

- ข้อมูลการจอง การชำระเงิน และรูปสลิป: 5 ปีนับจากวันใช้บริการ ตามที่กฎหมายบัญชีและภาษีกำหนด
- ลิงก์ติดตามการจอง: หมดอายุ 7 วันหลังเวลานัด
- ลิงก์ที่ได้จากการค้นหาด้วยเบอร์โทรหรือจาก "การจองของฉัน": หมดอายุภายใน 30 นาที
- การเชื่อมการจองกับ LINE: จนกว่าคุณจะขอยกเลิกหรือขอลบข้อมูล
- ความยินยอมรับข่าวสาร: จนกว่าคุณจะถอนความยินยอม

เมื่อพ้นระยะเวลา หรือเมื่อคุณขอลบและไม่มีเหตุที่กฎหมายให้ต้องเก็บไว้ เราจะลบหรือทำให้ระบุตัวคุณไม่ได้

## 6. สิทธิของคุณ

คุณมีสิทธิ์:
- ขอดูหรือขอสำเนาข้อมูลของคุณ
- ขอแก้ไขข้อมูลให้ถูกต้อง
- ขอลบ หรือขอให้ทำให้ข้อมูลระบุตัวคุณไม่ได้
- คัดค้าน หรือขอให้ระงับการใช้ข้อมูล
- ขอรับข้อมูลในรูปแบบที่อ่านด้วยเครื่องได้
- ถอนความยินยอมรับข่าวสารได้ทุกเมื่อ การถอนไม่กระทบการจองของคุณ
- ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.)

ใช้สิทธิ์ได้โดยโทรหรือทักแชท LINE ของร้าน (ช่องทางในข้อ 1) ร้านอาจขอยืนยันตัวตน เช่น ให้ยืนยันเบอร์โทรที่ใช้จอง และจะตอบภายใน 30 วัน

ข้อมูลบางส่วนอาจลบทันทีไม่ได้ เช่น หลักฐานการชำระเงินที่กฎหมายกำหนดให้เก็บ ร้านจะแจ้งเหตุผลให้ทราบ

## 7. การดูแลความปลอดภัย

- เว็บไซต์ใช้การเชื่อมต่อแบบเข้ารหัส (HTTPS)
- รูปสลิปเก็บในพื้นที่ที่ไม่เปิดสาธารณะ เปิดดูได้ผ่านลิงก์ชั่วคราวเท่านั้น
- พนักงานเข้าระบบด้วย PIN ของตัวเอง และเข้าได้เฉพาะสาขาที่ทำงาน การเข้าถึงข้อมูลการเงินของเจ้าของร้านต้องยืนยันตัวตนเพิ่ม
- การจองแบบไม่เข้าสู่ระบบใช้ลิงก์ติดตามที่สุ่มขึ้นใหม่ทุกครั้ง และหมดอายุตามข้อ 5

## 8. การเปลี่ยนแปลงนโยบาย

ร้านอาจปรับนโยบายนี้เมื่อระบบหรือกฎหมายเปลี่ยน ฉบับใหม่จะแสดงในหน้าจองพร้อมเลขฉบับ และใช้กับการจองหลังวันที่ประกาศ
