# การรับข่าวสารและโปรโมชัน

ถ้าคุณเลือก "รับข่าวสารและโปรโมชัน" Ifeew's Thaimassage จะใช้ชื่อ เบอร์โทร อีเมล (ถ้ามี) และ LINE (ถ้าเข้าสู่ระบบด้วย LINE) เพื่อแจ้งโปรโมชัน ส่วนลด บริการใหม่ และข่าวสารของร้าน

- ไม่บังคับ ไม่เลือกก็จองได้ตามปกติ
- ส่งไม่บ่อย และเฉพาะเรื่องของร้านเท่านั้น ไม่ส่งข้อมูลให้ร้านอื่นหรือผู้ลงโฆษณา
- ยกเลิกได้ทุกเมื่อ โดยโทร 092-576-6293 หรือทักแชท LINE ของร้าน หรือบล็อก LINE Official Account ของร้าน
- การยกเลิกไม่กระทบการจองหรือข้อความยืนยันและเตือนนัด

รายละเอียดการใช้ข้อมูลทั้งหมดอยู่ในนโยบายความเป็นส่วนตัวของร้าน
