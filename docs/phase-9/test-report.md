### ปัญหาที่พบและแก้แล้ว (migration 024)

1. **Guest เบอร์เดียวจองพร้อมกันทะลุเพดาน 3 การจอง (ได้ 10)** — ตรวจแล้วค่อยสร้างโดยไม่ล็อก → ล็อกต่อบริษัท+เบอร์ก่อนนับ
2. **คำนวณค่ามือพร้อมกัน (เปิดแดชบอร์ด/รายงาน/รอบจ่ายพร้อมกัน) แล้ว error** → ทำทีละรายการต่อบริษัท
3. ข้อความ error ภาษาอังกฤษเมื่อสลิปซ้ำ / รอบจ่ายซ้ำพร้อมกัน → ข้อความไทย
4. รายจ่ายสาขาที่บันทึกหลังเที่ยงคืนขณะร้านยังเปิด ได้วันที่ตามปฏิทิน → ใช้วันทำการของสาขา

## ตรวจความปลอดภัยของ schema (`node lint.mjs ../..`)

- ทุกตารางใน public เปิด RLS, ไม่มี policy DELETE/ALL
- ทุก SECURITY DEFINER ตั้ง `search_path`
- ไม่มี Function ใน public ที่ลืม revoke จาก PUBLIC
- anon เรียกได้เฉพาะ `get_available_slots`, `get_current_policies`, `get_public_company`
- anon อ่านได้เฉพาะข้อมูลสาธารณะ (สาขา, เวลาทำการ, บริการ, ราคาขาย — ไม่มีค่ามือ)
- ตารางการเงิน/คิว/การจอง ไม่มีสิทธิ์เขียนตรงจาก Client (ผ่าน Function เท่านั้น)
