# คู่มือใช้งาน Ifeew's Thaimassage

## สำหรับเจ้าของร้าน (OWNER)

**เข้าสู่ระบบ:** Staff App → แท็บ “เจ้าของร้าน” → กด PIN เจ้าของร้าน 6 หลัก (ใช้ได้ทุกเครื่อง ไม่ต้องผูกเครื่อง)
ครั้งแรก/ลืม PIN: กด “เข้าด้วยอีเมล” → อีเมล + รหัสผ่าน → เมนู ตั้งค่าเครื่อง → “PIN เจ้าของร้าน”
**PIN นี้เข้าถึงข้อมูลการเงินทั้งหมด อย่าให้ใครเห็นตอนกด** (กดผิดหลายครั้งถูกล็อกชั่วคราว)

**ตั้งค่าครั้งแรก**
1. สาขา → เวลาทำการและวันหยุด (สาขาใหม่ปิดอยู่จนกว่าจะตั้ง)
2. บริการและราคา → ชื่อบริการ, ระยะเวลา, ราคา, ค่ามือหมอ แยกสาขาได้
3. เตียงและอุปกรณ์ → จำนวนต่อสาขา, บริการใช้อะไร, บัญชี PromptPay + SlipOK Branch ID
4. พนักงาน → เพิ่มพนักงาน, ตั้ง PIN; ประกันมือ/ลงเวลา → หมอประจำ/หมอวิ่ง, ยอดประกันต่อวัน
5. ตารางงาน → กะรายวัน (คัดลอกสัปดาห์ก่อนได้)
6. ตั้งค่าเครื่อง → ผูกแท็บเล็ตหน้าร้านแต่ละสาขา (ทำบนแท็บเล็ตเครื่องนั้น)
7. ตั้งค่าบริษัท → การจอง/มัดจำ, เกณฑ์รายจ่ายสูง, ส่วนลดสูงสุดของพนักงาน

**ประจำวัน/สัปดาห์**
- ภาพรวมทุกสาขา → “ต้องดำเนินการ”: กะรอตรวจ, ปิดยอดรอตรวจ, คำขอยกเลิกรายจ่าย, มัดจำรอคืน
- กะและเงินสด → อนุมัติ/ปฏิเสธกะ (ดูผลต่างเงินสด)
- ปิดยอดรายวัน → อนุมัติ (ใส่ยอดปรับปรุงได้ เช่น เงินขาด) / ปฏิเสธพร้อมเหตุผล
- ค่ามือหมอ → สร้างรอบจ่าย (ถึงเมื่อวาน) → ตรวจ → ยืนยันจ่าย (ระบุเลขอ้างอิงการโอน)
- ประกันมือ/ลงเวลา → ดูผลรายวัน, “ให้/ไม่ให้” ประกันพร้อมเหตุผล (เช่น ร้านให้กลับก่อน)
- รายงาน → การเงินรายวัน/เดือน/ปี, รายจ่ายผิดปกติ, ส่งออก CSV
- งวดบัญชี → ล็อกเดือนที่ปิดยอดครบแล้ว (เปิดใหม่ต้องมีเหตุผล)
- สำรองข้อมูลตาม `docs/deploy.md` (แพ็กเกจ Free ไม่มีสำรองอัตโนมัติแบบย้อนเวลา)

## สำหรับพนักงาน

**เข้าสู่ระบบ:** แท็บเล็ตหน้าร้าน → แตะชื่อตัวเอง → กด PIN 6 หลัก (กดผิดหลายครั้งจะถูกล็อกชั่วคราว)
ไม่ได้ใช้งานสักพักระบบออกจากระบบเอง

**เริ่มวัน**
1. คิว → “ลงเวลา” → เลือกชื่อ → PIN (หมอประจำต้องลงเวลาเข้า-ออกให้ครบกะจึงได้ประกันมือ)
2. หน้าร้าน (POS) → “เปิดกะ” → ใส่เงินทอนเริ่มต้น

**รับลูกค้า**
- Walk-in: หน้าร้าน → “รับลูกค้า Walk-in” → ค้นหาเบอร์ (หรือลูกค้าทั่วไป) → เลือกบริการ → ระบบเลือกเวลาว่างเร็วสุด → แจ้ง **เลขคิวบนจอ** ให้ลูกค้า
- ลูกค้าที่จอง: หน้าร้าน → “เช็กอิน”
- คิว → “เรียกคิว” เลือกหมอ → หมอกด “หมอกด PIN” เพื่อรับ/เริ่ม/จบ (หรือหน้าร้านกดแทน)
- ระหว่างนวด: “ต่อเวลา”, “เปลี่ยนหมอ” (ต้องมีเหตุผล), กดผิดย้อนได้ภายใน 15 นาที

**คิดเงิน**
1. การ์ดลูกค้า → “ชำระเงิน” → ใส่ส่วนลด (ถ้ามี, ต้องมีเหตุผล) → “ออก Invoice” (มัดจำหักให้อัตโนมัติ)
2. เงินสด: ใส่ยอด + เงินที่รับมา (ระบบคำนวณเงินทอน)
3. QR/โอน: ลูกค้าโอนผ่าน QR หน้าร้าน → “ถ่ายรูปสลิป” → ระบบตรวจ (ถ้าตรวจไม่ได้ ให้ดูยอดเข้าบัญชีจริงแล้วยืนยันพร้อมเหตุผล)
4. ทิป: ใส่ยอดและเลือกหมอ; ทิปเงินสดจ่ายหมอด้วยปุ่ม “จ่ายทิป”

**ระหว่างวัน**
- รายจ่าย → จำนวนเงิน + หมายเหตุ + ถ่ายรูปหลักฐาน (จ่ายจากลิ้นชักต้องเปิดกะ); บันทึกผิดในกะเดียวกันยกเลิกได้ทันที
- หน้าร้าน → “เงินเข้า/ออกลิ้นชัก” (แลกเหรียญ, นำเงินฝาก)

**ปิดวัน**
1. หน้าร้าน → “ปิดกะ” → นับเงินสดทั้งหมดแล้วกรอก (ไม่เห็นยอดที่ควรมีก่อน) → ถ้าไม่ตรงต้องใส่เหตุผล
2. ปิดยอดรายวัน → ตรวจตัวเลข → “ส่งปิดยอด”
3. คิว → “ลงเวลา” ออกงาน

**หมอ:** เมนู “งานของฉัน” ดูงานที่ทำ, ค่ามือประมาณการ, เงินเติมประกันมือ และยอดค้างจ่าย
